# Agent instructions

Corpus OS is an application proof layer. Project 0 owns shared meaning; TranchNode owns reusable continuity mechanics; this repository owns ingestion, navigation, and the `ring_6` experiment.

Before changing behavior:

1. Read `README.md`, `docs/architecture.md`, `docs/profile-matrix.md`, and `corpus/manifest.json`.
2. Name the proof task or invariant the change exercises.
3. Preserve the nine Project 0 node kinds; UI state is not ontology.
4. Preserve quotations, inferences, confidence, evidence, validation, and authority as separate fields.
5. Never mutate admitted source bytes or an existing branch.
6. Never infer lineage from similarity, repetition, graph density, or retrieval rank.
7. Never add a JSON canonicalizer here. Implement `CanonicalAddressingPort` only with the single version adopted by Project 0.
8. Never disguise Project 0 `rejection` as TranchNode v0.1 tension, dispute, absence, or supersession.
9. Every return path must verify exact bytes or fail explicitly.
10. Run `npm run check` before publishing.

Pull requests must state the meaning-contract effect, fixtures changed, checks run, compatibility effect, and unresolved tensions.
